# 工作日清单 · 每日待办

一个纯前端的每日待办 / 工作日程小工具，单个 HTML 文件即可运行，数据保存在浏览器本地（localStorage），无需后端。

## 功能

- 日历视图：月历切换，当天高亮，有未完成任务的日期带标记
- 待办管理：新建 / 批量添加 / 批量删除，支持截止时间（DDL）、优先级（高 / 中 / 低）、标签、打勾完成
- 数据统计：今日完成率、本周任务趋势、常用标签
- 快捷备忘、导出 / 导入 JSON
- 主题切换：7 套单色渐变主题，选择自动记忆

## 使用

直接在浏览器打开 `index.html` 即可。
